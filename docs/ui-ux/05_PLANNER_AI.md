# 1年Planner・日別AI UI/UX仕様書

## 1. 対象

- `GET /chart/{token}/planner.pdf`
- `GET /chart/{token}/planner-ai?date=YYYY-MM-DD`
- `GET /demo/neko/planner.pdf`
- `GET /demo/neko/planner-ai?date=YYYY-MM-DD`
- FULL版・ACG bundleに含まれる1年Plannerと、「この日の星をAIで読む」導線

## 2. 商品上の位置づけ

- FULL版には1年Plannerを含む。
- ACG bundleにも1年Plannerを含む。
- Planner単体は別SKUだが当面休止中であり、新規販売CTAを出さない。
- PlannerからACGが付属するように見せない。ACG bundle側からはPlanner同梱を明記する。
- Birth Chart MuseumはPlannerおよび全有料商品に含めない。

## 3. Planner PDF生成

- 鑑定結果から「あなたの1年トランジット手帳（PDF）を作成・保存」相当のCTAを表示する。
- 生成には20〜30秒程度かかる可能性を事前に示す。
- 押下後は処理中表示へ変え、二重押下を防ぐ。
- 完了時はブラウザのダウンロードを開始し、開始しない場合の再操作方法を示す。
- Plannerの基準日、対象期間、出生図、長期トランジットは現在のチャートデータから生成する。
- PDF生成のために発行権を再消費したり、新しい鑑定トークンを作ったりしない。
- 休日国セレクタは、全言語で一貫した選択肢と「休日なし」を提供できるまで購入者画面へ表示しない。

## 4. PDF表示品質

- JA / EN / ES / DEで表紙、目次、月見出し、曜日、月相、日別文、凡例を同じ言語にする。
- 非日本語PDFに可視日本語を混在させない。固有名詞または内部メタデータの許容可否はテストごとに明示する。
- 長いドイツ語、アクセント付きスペイン語、日本語の禁則で文字切れ・重なり・豆腐がない。
- 月間カレンダー、日別ページ、出生図、トランジット情報が欠落しない。
- ファイル名に言語と対象期間を含め、別言語版を上書きしにくくする。

## 5. 「この日の星をAIで読む」

- Plannerまたは鑑定結果から、対象日と同じ `lang` を付けて日別AIページを開く。
- 画面に選択日、日別の主要情報、AIへ渡す依頼文、コピー操作を表示する。
- 日付は `YYYY-MM-DD` で受け、無効日付や対象外期間は選択言語のエラーにする。
- AI依頼文は対象日を明示し、保存済み計算結果を再計算しないよう指示する。
- 非日本語表示では、表示用AIデータから `*_ja` 等の日本語補助フィールドを再帰的に除外する。
- 除外は表示用コピーにだけ行い、正規YAML、保存データ、占星術計算結果を変更しない。
- コピー完了、共有失敗、データ欠落等の状態も同じ言語で表示する。

## 6. 言語とリンク

- JA / EN / ES / DEをサポートする。
- 鑑定ページ、Neko、Planner、日別AIの相互リンクは同じ `lang` を引き継ぐ。
- Etsy等の言語別導線では、暗黙のfallbackに頼らず `lang` を明示する。
- 将来の言語追加はPlannerデータを複製せず、辞書、日付書式、フォント、テストを追加する。

## 7. エラー仕様

| 状態 | 表示・動作 |
|---|---|
| Planner生成中 | 所要時間と待機案内。二重押下不可 |
| Planner生成失敗 | 再試行できる状態へ戻し、内部例外を表示しない |
| 無効な日付 | 同じ画面に選択言語の入力エラー |
| 日別データなし | 対象期間または元データを確認する案内 |
| 期限切れチャート | 新規計算せず、保存済み成果物と問い合わせ方法を案内 |
| コピー失敗 | 手動選択またはTXT保存など代替操作を示す |

## 8. 受入テスト

### 自動テスト

- FULL版とACG bundleでPlanner URLが表示され、非対象商品で表示されない。
- 4言語のPDFを生成し、期待ページ数、主要見出し、対象期間、可視誤言語を検査する。
- PDFのテキスト抽出だけでなく、代表ページを画像化してレイアウトを確認できるようにする。
- 4言語の日別AI画面、AI依頼文、コピー完了、入力エラーを検証する。
- 非JAの表示用AIデータから `*_ja` が除外され、元データが不変である。
- `lang` と `date` が全リンクで保持される。
- 生成ボタンの多重実行防止と、失敗時の状態復帰を検証する。

主なテスト: `tests/test_planner_delivery.py`, `tests/test_planner_export.py`, `tests/test_planner_locales.py`, `tests/test_planner_holidays.py`, `tests/test_planner_ai.py`, `tests/test_neko_demo.py`。

### 手動テスト

- 各言語の表紙、月間ページ、日別ページ、出生図ページ、末尾案内を目視する。
- 長いドイツ語見出し、スペイン語アクセント、日本語改行を確認する。
- 実ブラウザで生成中表示から自動ダウンロードまで確認する。
- Planner内または画面のリンクから同じ日・同じ言語の日別AIへ進む。
