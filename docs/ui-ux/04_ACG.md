# ACG UI/UX仕様書

## 1. 対象

- 公開ACG地図 `GET /acg`
- 保存済み鑑定からの自動読込 `?load=/chart/{token}.yaml`
- ACG bundleのPersonal ACG `GET /chart/{token}/acg-app/`
- 3D地球儀 `GET /acg/globe-demo`
- `/api/acg/mundane`, `/api/acg/personal`, `/api/geocode`

## 2. 利用モード

### 2.1 公開・貼付モード

- 日付指定のマンデン線と、購入者が貼り付けた個人YAMLを地図へ表示できる。
- YAMLはブラウザからAPIへ送るが、個人ACG APIはステートレスで保存・ログ出力しない。
- 地点検索、レイヤー切替、線の説明、地点付近の線、AI用YAML出力を提供する。

### 2.2 鑑定結果からの自動読込

- Chart CompanionのACGリンクは、現在の鑑定トークンのYAMLを `load` へ指定する。
- 開いた時点で個人YAMLを自動読込し、購入者に再貼付を要求しない。
- `load` の値は同一サービス上の許可されたチャートYAML URLに限定する。
- ページURLやRefererからトークンが不要な外部へ漏れないようにする。

### 2.3 Personal ACG

- ACG bundleのPersonal Editionだけに、個人データ入りの専用アプリを提供する。
- iOS等でホーム画面へ追加できるmanifestとservice workerを提供する。
- 別のチャートトークンや一般FULL版からPersonal ACG専用URLを開けない。

## 3. 出生時刻

- 個人ACGは正確に確認された出生時刻を必要とする。
- 出生時刻がおおよそ／不明の鑑定結果では、「あなたのデータでACGを開く」を表示しない。
- APIへ不確かな時刻のYAMLが送られた場合は計算を開始せず、選択言語の安全なエラーを返す。
- 出生時刻が後から判明した場合は再発行が必要であることを案内する。

## 4. 地図操作

- 初期表示時に地図本体、凡例、検索、レイヤー操作が識別できる。
- 線種、天体、ASC / DSC / MC / ICを色だけでなくテキストでも区別する。
- 経度180度またぎの線が地図を不自然に横断しない。
- 地点検索結果から対象地点へ移動し、付近の線と距離・意味を確認できる。
- 地理院等の日本向けレイヤー名を非日本語UIへ固定表示しない。
- 都市検索データ内の日本語市区町村名・国名は地図データとして許容例外とし、購入者向けUIの誤言語混入には数えない。
- AI用YAMLには出力言語を明示し、地図上の計算結果を勝手に再計算させない依頼文を付ける。

## 5. 3D地球儀

- `/acg` から移動するとき現在の `lang` を引き継ぐ。
- 操作説明、読込状態、ツールチップ、エラー、戻る導線を同じ言語にする。
- 3Dが利用できない端末や読込失敗時に、空白画面だけにせず案内を表示する。
- 公開デモと購入者の個人データ表示を混同させない。

## 6. 言語

- JA / EN / ES / DEで地図タイトル、検索、レイヤー、状態、解釈、AI出力、APIエラーを揃える。
- `lang` 未指定は既存互換の日本語とする。
- 地図からAPIと3D地球儀へ `lang` を付与する。
- 一般ACG URLを個人ACG URLへ変える場合も、選択言語とYAML自動読込の両方を維持する。

## 7. エラー仕様

| 状態 | 表示 |
|---|---|
| YAML空欄／形式不正 | 貼付内容を確認する短い案内。内部例外は表示しない |
| 西洋出生図がない | ACGに必要なデータがないことを表示 |
| 出生時刻不確か | 正確な時刻と再発行が必要であることを表示 |
| 地点検索失敗 | 入力変更または座標指定を案内 |
| API通信失敗 | 再試行可能な状態に戻し、読み込み中表示を解除 |
| 3D初期化失敗 | 2D地図へ戻る選択肢を残す |

## 8. 受入テスト

### 自動テスト

- 4言語のタイトル、検索ラベル、レイヤー、エラー、AI出力言語を確認する。
- `load` 付きURLで自動読込処理が動き、言語切替後もloadを保持する。
- 正確な時刻だけ個人ACGを計算し、不確かな時刻は計算コアを呼ばない。
- Chart Companionの個人ACGリンクとプロンプトURLが同じトークンを指す。
- Personal ACGのアクセス制御、manifest、service worker、ZIP内起動ファイルを検証する。
- 経度180度分割、線グループ、地点近傍検索の計算結果を検証する。
- レスポンスのReferrer-Policyと、個人APIが保存処理を呼ばないことを確認する。

主なテスト: `tests/test_acg_api.py`, `tests/test_acg_core.py`, `tests/test_acg_locales.py`, `tests/test_acg_map_template.py`, `tests/test_personal_acg_pwa.py`, `tests/test_chart_yaml_copy.py`。

### 手動テスト

- スマートフォンとPCでズーム、パン、地点検索、レイヤー切替、AI用YAMLコピーを行う。
- FULL版の相談モードから開き、自分のデータが貼付操作なしで表示される。
- 4言語で2D地図から3D地球儀へ移動し、戻れる。
- 都市データの日本語例外以外に、非日本語UIへ日本語が露出しない。
