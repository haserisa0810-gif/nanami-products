# 鑑定結果・Chart Companion UI/UX仕様書

## 1. 対象

- `GET /chart/{token}`
- YAML、SVG、プロンプト、ZIP、Planner等の結果ページ内導線
- Chart Companionの「鑑定モード」「相談モード」
- 期限内再訪と、発行済みデータの再利用

## 2. 情報の優先順位

1. ページが誰の、どの基準日時・出生情報の結果か
2. AIへ渡す主操作
3. 選択中のモードと、その意味
4. 商品に含まれる追加機能への導線
5. 保存用URL、ZIP、個別YAML等の補助操作

商品に含まれない機能を表示してはならない。表示判定は商品名だけでなく、保存済みYAMLの実データとoptionsを使う。

## 3. Chart Companion

### 3.1 共通

- 初期状態は「鑑定モード」とする。
- 選択中モードをボタン状態、ラベル、説明文で示し、色だけに依存しない。
- AIへ送る、コピー、TXT保存は同じモードのプロンプトと同じ選択YAMLを使う。
- モード変更後は、直前モード用に準備した共有ファイルを再利用しない。

### 3.2 鑑定モード

- 総合鑑定用の通常プロンプトを利用する。
- FULL／小惑星／軽量版等のYAML選択がある場合、選択中の版を使う。

### 3.3 相談モード

- 最初から長い総合鑑定を出さず、相談テーマを確認するChart Companionプロンプトを利用する。
- 旅行、移住、活動場所、土地との相性の相談ではACGを補助情報として案内する。
- 正確な出生時刻を持つ西洋占星術チャートでは、相談モード選択時だけACG案内カードを表示する。
- ACG案内カードは青緑の背景・枠で周囲と区別し、リンク文字を太字にする。
- 日本語リンク文言は「あなたのデータでACGを開く」とする。
- 案内文は、元のYAMLが自動読込され、AIにYAMLを再表示させる必要がないことを明記する。
- ACGリンクは `/acg?lang={lang}&load=/chart/{token}.yaml` 相当へ接続し、相談プロンプト内の一般ACG URLも同じ個人データ付きURLへ置換する。
- 出生時刻がおおよそ／不明の場合、ACG案内カードを表示しない。

## 4. 商品別表示

| 状態 | 必須表示 |
|---|---|
| 西洋基本版 | 出生図、通常AI操作、保存・個別DL。利用可能なら次回Add-on導線 |
| FULL版 | FULLデータ、31日等のトランジット、1年Planner。ACGやMuseumを同梱扱いにしない |
| ACG bundle | ACG、1年Planner、Personal Edition対象機能。Museumを同梱扱いにしない |
| 四柱推命 | 四柱推命SVGと専用プロンプト。西洋占星術・ACG固有UIを出さない |
| トランジット専用 | 対象日時・場所とトランジット用途。出生図前提のUIを出さない |
| Add-on統合結果 | ベースデータと追加データを反映し、次回発行への導線を商品仕様に合わせる |

## 5. 保存・再訪・期限

- 保存用URLはコピーしやすくする。
- 初回の自動ダウンロードと、手動で再ダウンロードする操作を区別する。
- 同じトークンへの再訪では、保存済みの同じ結果を表示し、再計算や再消費を行わない。
- 期限切れはHTTP状態と画面案内を一致させる。期限切れ後も手元のZIPが利用できることはREADME等で案内する。
- 個別YAML、SVG、プロンプト、ZIPのリンクは同じトークンと同じ言語を指す。
- 別アプリへ自動読込するリンクでは、現在のデータを取り違えない。

## 6. 言語

- JA / EN / ES / DEでモード名、説明、共有操作、エラー、ダウンロード名、ACG案内を揃える。
- ACG、Planner AI、Neko等へ移動するとき `lang` を引き継ぐ。
- 非日本語画面に日本語の購入者向けラベルを混在させない。ただし保存済みYAMLの内部キー、地名検索データ等の許容例外はUI表示テストから除外する。

## 7. 受入テスト

### 自動テスト

- 初期モードが鑑定モードである。
- モード切替でラベル、説明、プロンプト、ACGカード表示が同期する。
- 4言語でACGリンク文言と個人YAML自動読込URLが正しい。
- 正確な時刻ではACGリンクが出て、不明／おおよそでは出ない。
- ACGカードが青緑の背景・枠、太字リンクという仕様を維持する。
- 西洋基本、FULL、四柱推命、トランジット、Add-onで不要な機能が露出しない。
- AI共有、コピー、TXT保存が同じpayload builderを使う。
- 期限、キャッシュ、個別ダウンロードのレスポンスヘッダーを確認する。

主なテスト: `tests/test_chart_yaml_copy.py`, `tests/test_multilingual_review_fixes.py`, `tests/test_yaml_v2_time_provisional.py`, `tests/test_chart_expiry.py`, `tests/test_chart_download_zip.py`。

### 手動テスト

- 相談モードへ切り替え、ACGカードが鑑定モードの主CTAと混同せず十分目立つ。
- ACGを開いた直後に保存済みデータが読み込まれる。
- 新しいタブから戻っても鑑定ページの状態を失わない。
- 長い名前、長い地名、スマートフォン幅で崩れない。
- コピー、共有、TXT保存を実ブラウザで1回ずつ確認する。
