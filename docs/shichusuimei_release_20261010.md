# 四柱推命候補版の統合

本番稼働コミット `8c25fc0a59` の後続修正をマージし、購入UI、多言語対応、URLの365日期限、ACG、既存商品の処理を保持したうえで、四柱推命の構造計算・保存済み年抽出機能を追加する。元の作業領域にある別機能の未コミット変更はそのまま保持する。

- 保存データの検証・抽出テスト用の架空データ4件を `tests/fixtures/shichusuimei/` に配置し、無視されたローカルtmpに依存しないようにした。
- 個人の出生情報と生成FullはGitやデプロイソースへ含めない。
- デプロイは既存の候補スクリプトでトラフィック0%、本番切り替えは別の明示指示後。
- テスト用basetempは事前に親ディレクトリを作成し、OneDrive外へ置く。
- 新しい保存済み年選択のUI/APIは読み取りと抽出のみ。購入者の保存原本、価格、購入手順は維持する。
- 旧命式が保存されたままの場合、デプロイによって原本を再計算しない。未収録年を新しく生成しない。
