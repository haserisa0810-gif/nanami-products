# 四柱推命の構造分析 v1

エンジン `0.4.0` は、既存の四柱・蔵干・十神・五行・十二運・身強スコアを保持し、
`systems.shichusuimei.normalized_data` に次の計算材料を追加する。
生成済みの商品データを更新する処理ではなく、新たに生成する YAML に適用される。

| パス | 内容 |
| --- | --- |
| `structural_analysis.methodology` | 方式のバージョン、全係数、時柱の採用範囲、未評価事項 |
| `structural_analysis.roots_and_exposure` | 天干ごとの通根、本気／副次／余気、同干／同五行の区別、透干位置 |
| `structural_analysis.ten_god_strength` | 十神の重み・構成比・配置・透干の根の参照 |
| `structural_analysis.ten_god_groups` | 比劫・食傷・財・官殺・印の共通集計 |
| `structural_analysis.ten_god_flow` | 食神生財、傷官生財、官印相生、殺印相生、食神制殺、傷官見官、比劫剋財、財剋印の併存材料 |
| `structural_analysis.day_master_support` | 支持比率、日主の根、身強／身弱候補、特殊格の検討フラグ |
| `structural_analysis.pattern_analysis` | 月支蔵干・透干からの格局候補と根拠 |
| `structural_analysis.useful_god_analysis` | 扶抑・通関・月令格局を分けた候補、方式間の食い違い、判断保留 |
| `structural_analysis.element_flow` | 相生の接続、欠ける両端、3五行の主要経路、日主→食傷→財の経路 |
| `structural_analysis.interactions` | 原局の合・冲・刑・害・破・三合、作用する柱と十神、合化の条件材料 |
| `daiun.items[].structural_analysis` | 各大運×原局の作用、天干の生剋、透出する原局蔵干、追加五行の材料 |
| `annual_fortune.structural_analysis` | 現在の流年×原局×現在の大運 |
| `annual_forecasts.items[]` | 現在の立春年から10年分の流年×原局×大運候補 |

大運・流年の追加商品にも `daiun`、`annual_fortune`、`annual_forecasts` を収録する。
追加商品の原局根拠 ID は、一緒に使う同一出生情報の基本版で参照する。
旧基本版に根拠 ID がない場合も、追加商品中の干支・十神・作用対象を解釈できるが、
未収録の構造指標を AI が再構成することは想定しない。

## 係数と意味

`services/shichusuimei_structure.py` の `structural_heuristic_v1` は、独自の説明可能な近似方式。
古典や特定流派で確定した数値、鑑定精度の実証値として提示しない。

- 蔵干1個は `1.0`、2個は `0.7 / 0.3`、3個は `0.6 / 0.3 / 0.1`。
  既存の蔵干表の順序を使う。節入り後の日数による司令は使わない。
- 天干の基礎重みは `1.0`。月支の蔵干に `1.5` を掛ける。
- 月支の代表五行と同じ五行は `1.5`、そこから生まれる五行は `1.2`、
  月令を生じる五行は `1.0`、月令を剋す五行は `0.8`、月令に剋される五行は `0.6`。
  土月を含む季節近似で、実際の寒暖燥湿とは区別する。
- 根のスコアは、同五行の蔵干の重みの合計。同干／異なる陰陽の同五行を根拠ごとに区別する。
  根を持つ支に冲等があれば併記するが、根の削除や重みの減算はしない。
- 日干自身は十神強度の比肩に数えない。五行集計には日干を1回含める。
- 日主と印の支持比率が `0.4` 未満は身弱候補、`0.55` 超は身強候補、間は中間候補。
  相対的な材料で、従来の `features.strength` を置き換える確定判定ではない。

扶抑の喜方向は身弱候補で印・比劫、身強候補で食傷・財・官殺。
反対方向を忌候補として記録するが、個別の用神を選び切る処理ではない。
支持比率が極端（根なしで `0.2` 未満、または `0.85` 超）なら特殊格の検討を要求し、扶抑の喜忌を保留する。

通関は、相剋する2五行がそれぞれ全体重みの `20%` 以上を占める場合に、
その間を相生でつなぐ五行を材料候補として記録する。扶抑と食い違えば `conflicting_rules` に残す。
格局法の月令用神は、扶抑法の補う五行と同じ意味として統合しない。

`confidence: low` は未完成の方式であることを示すラベル。統計的な確率ではない。
`definitive_pattern` と `definitive_useful_god` は `null`。
格の成敗・救応、従格・専旺格、調候、流派横断の喜神／忌神の確定は今回の対象外。

## 合化と作用対象

干合・六合では、月令の支持、化五行の透出・根、原局内の隣接、争合、関係支の冲を記録する。
運の干支には原局の位置順を当てはめず、隣接条件を `null` にする。
三合は3支の有無、中心支の有無、冲、月令の支持を記録する。
2支だけの組は、中心支を含む半合と、中心支を欠く拱の材料を区別する。

全結果で `confirmed: false`、`element_change_applied: false`。
条件が揃うこと、組合せが存在すること、五行が化すことは別の判定である。
既存表の午未六合の火を保持し、土を採る方式との差も明示する。
六破を加えて、六合等と重なる関係も独立して併記する。

## 大運と流年

大運10項目をそれぞれ原局と比較する。流年は立春年を基準に10年分を生成するため、
1月時点の生成では前年の干支から始まる。

`natal_analysis` に流年×原局、`daiun_contexts[].analysis` に流年×大運と
両方が関わる三合・三刑を収録する。既存の近似起運年齢の年月を出生日時へ加え、
各大運の `approx_start_at` / `approx_end_at` を求める。月末・閏日の加算は行き先の月末に丸める。
現在の大運はその近似期間 `[開始, 終了)` で選ぶ。流年は各年の立春から翌年の立春までの期間で
大運の近似期間と重なり判定し、切替年は両方の候補と `overlap_start_approx` / `overlap_end_approx` を残す。
年差だけの年齢で選ばない。起運年齢自体は簡易換算なので、交運日時を確定する計算ではない。

五行の追加量は、原局の季節係数を固定した加算材料。
原局が別の命式になる、合化する、冲で五行が消える、喜忌が自動的に逆転するとは扱わない。

計算関数には検証用の `as_of`（タイムゾーン付き日時）と `annual_years`（1〜20、既定10）を指定できる。
`as_of` を指定した場合、計算基準とエンジン側の `generated_at` がその日時になる。

## 出生時刻と互換性

出生時刻不明・推定の場合、新しい構造分析は時柱を除外し、扶抑の喜忌を保留する。
大運・流年の新しい分析も同じ三柱を使う。旧 `interactions` と `annual_fortune.relations` からも
時柱が関わる合・冲・三合等を除外する。仮置き時柱そのものと旧五行集計・身強スコア等は互換性のため保持し、
`time_sensitive_reference` に参考値の範囲を明示する。
その前提は `input.assumptions`、`unknowns`、`methodology.time_basis` に明示し、
鑑定・相談・追加商品・複合版のプロンプトから新しい構造分析を優先させる。
共通の構造分析ルールを全プロンプトへ適用する。旧YAMLに残る仮置き時柱の作用も確定根拠にさせず、
旧基本版で解決できない根拠 ID を推測で補完させない。
節入り・日替わり付近では年・月・日柱も時刻の影響を受けるため、三柱が必ず不変とは保証しない。

配置材料は共通エンジンから得る。テーマ別の金運・仕事運・恋愛運などの独立した吉凶採点は追加しない。

## 参照した原典と独自実装の区別

- [『子平真詮』八・論用神](https://www.donglishuzhai.net/chapter/3721.html)：月令と格局を軸に取用する考え方。
- [同 九・論用神成敗救應](https://www.donglishuzhai.net/chapter/3722.html)：命式全体の配置により成敗・救応を検討する考え方。
- [同 五・論十干合而不合](https://www.donglishuzhai.net/chapter/3718.html)：干の組合せの存在と、隔たり・競合等を含む作用の区別。

これらは候補を即座に確定しない設計の参考であり、今回の係数や全流派共通の成立条件を裏付ける資料ではない。
三合の争合・競合は未評価として明示する。六合・破などの重複関係は独立して併記し、相殺を自動適用しない。
