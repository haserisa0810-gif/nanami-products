## 変更内容

- ページの原文YAMLを解析し、全文プロンプトにもそのdocを渡す。同じ原文を共有する四柱推命では共有プロンプトも再利用する。
- 共有用YAMLが原文と異なる西洋の軽量版は独立に解析する。既存のエラー時フォールバックを保持したまま、内部呼び出し用の `parsed_doc` 引数を追加した。
- 表示・プロンプト経路の解析は `CSafeLoader` を利用し、C拡張のない環境では `SafeLoader` に戻す。グローバルなローダーの変更やprototypeモジュールへの依存追加は行っていない。
- 同じ原文をHTMLに二重埋め込みする代わりに、`FULL_YAML_INLINE` から先に定義済みの `SHARE_YAML` を参照する。西洋の全文のオンデマンド取得は維持する。
- 全文プロンプト生成に `prompt_build_ms` を追加し、計測区間の抜けを解消した。

命式・大運・流年の計算、保存済みYAML、プロンプト本文、年選択の検証と非同期準備、DB接続管理には変更なし。
