API Reference — v1.0

nanami-products
Calculation API

西洋占星術・四柱推命・トランジットの計算結果をJSON形式で返す、AIフレンドリーな占星術計算エンジンです。購入・保存処理は行いません。

Base URL: https://chart.nanami-astro.com Content-Type: application/json Auth: X-API-Key header OpenAPI: /docs

はじめに

このAPIは、既存の nanami-products 計算エンジンをRESTエンドポイントとして公開したものです。既存のUI・注文フロー・管理画面には影響しません。

設計方針： APIはJSONを返すだけです。DBへの保存・購入処理は行いません。計算結果は build_product_yaml() を経由して再利用されます。

利用可能なエンドポイント

エンドポイント役割推奨度
POST /api/calc/western西洋占星術（ネイタル＋小惑星）単体利用時
POST /api/calc/shichu四柱推命単体利用時
POST /api/calc/transitトランジット（日別・月別）単体利用時
POST /api/calc/combined上記3つを統合した本命API★ 推奨

処理時間の目安

通常、APIレスポンスは数秒以内に返ります。

エンドポイント目安
western（小惑星なし）1秒以内
western FULL（小惑星・トランジット含む）1〜3秒程度
combined（西洋・四柱推命・トランジット）1〜3秒程度
タイムアウト設定に注意：
初回アクセス時のCloud Run起動・外部天体データ取得・通信状況により、5〜15秒程度かかる場合があります。APIクライアント側のタイムアウトは、余裕を持って 30秒以上 に設定することを推奨します。
SVGホロスコープ図について：
SVGはAPIレスポンス本体には含まれません。レスポンス内の chart.svg_url から、必要な場合のみ別途取得してください。詳細は SVG / チャート画像 をご参照ください。

認証

全エンドポイントはAPIキー認証が必要です。リクエストのHTTPヘッダーに X-API-Key を設定してください。

ヘッダー

ヘッダー名値必須
X-API-Key 発行されたAPIキー required

設定例

curl 
-H "X-API-Key: your_api_key_here"
Python (requests) 
headers = {
  "Content-Type": "application/json",
  "X-API-Key":     "your_api_key_here",
}
response = requests.post(url, json=payload, headers=headers)
JavaScript (fetch) 
const response = await fetch(url, {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "X-API-Key":     "your_api_key_here",
  },
  body: JSON.stringify(payload),
});
APIキーは外部に公開しないでください。GitHubへのコミットやクライアントサイドコードへの埋め込みは避け、環境変数で管理することを推奨します。

Western API

POST /api/calc/western 西洋占星術

ネイタルチャート・小惑星・リリス・キロンを含む西洋占星術の計算結果を返します。四柱推命・トランジットは含みません。

リクエストパラメータ

パラメータ型必須説明
namestringoptional鑑定対象者の名前
birth_datestringrequired生年月日 YYYY-MM-DD
birth_timestringrequired出生時刻 HH:MM
birth_placestringoptional出生地（表示用）
latfloatrequired出生地の緯度
lonfloatrequired出生地の経度
timezonestringoptionalタイムゾーン識別子。例："Asia/Tokyo"。未指定時は Asia/Tokyo
tz_namestringoptionalタイムゾーン名（表示用）。timezone と併用
writingobjectoptional文章生成トーン指定（後述）
lat/lon と timezone の整合性：lat/lon と timezone は整合性を保つ必要があります。たとえば lat/lon にニューヨークの座標を指定しながら timezone を未指定（Asia/Tokyo）にした場合、計算結果が意図と異なります。海外出生地を扱う場合は必ず timezone を明示してください。不正なタイムゾーン文字列は INVALID_TIMEZONE エラーになります。

リクエスト例

{
  "name":        "テスト太郎",
  "birth_date":  "1990-01-01",
  "birth_time":  "12:00",
  "birth_place": "東京都",
  "lat": 35.6812,
  "lon": 139.7671,
  "writing": {
    "tone": { "sharpness": 40, "warmth": 80, "mystical": 30 },
    "focus_areas": ["career", "love"]
  }
}

raw_data に含まれる主なフィールド

フィールド内容
western.natalネイタルチャートデータ（天体配置・ハウス・アスペクト）
western.asteroids小惑星・リリス・キロンのデータ
chartSVG取得用の chart_id と svg_url（詳細は SVGセクション）

Shichu API

POST /api/calc/shichu 四柱推命

四柱推命の計算結果を返します。西洋占星術・トランジットは含みません。

リクエストパラメータ

パラメータ型必須説明
namestringoptional鑑定対象者の名前
birth_datestringrequired生年月日 YYYY-MM-DD
birth_timestringrequired出生時刻 HH:MM
birth_placestringoptional出生地（表示用）
genderstringrequired"male" / "female"
day_boundarystringoptional"23:00" のみ日替わりを23時扱いにする
timezonestringoptionalタイムゾーン識別子。例："Asia/Tokyo"。未指定時は Asia/Tokyo
tz_namestringoptionalタイムゾーン名（表示用）。timezone と併用
writingobjectoptional文章生成トーン指定
day_boundary の扱い："23:00" を指定した場合のみ day_change_at_23 = true として処理します。それ以外の値は無効（false）になります。
四柱推命の計算仕様：
本APIの四柱推命は 節入り基準（24節気） および 23時日替わり（子初） を採用しています。他流派との結果差異が生じる場合があります。

時刻は timezone パラメータで指定されたタイムゾーンのローカル時刻をそのまま使用します（未指定時は Asia/Tokyo）。lat/lon からの自動TZ判定および真太陽時補正は行っていません。

リクエスト例

{
  "name":         "テスト太郎",
  "birth_date":   "1990-01-01",
  "birth_time":   "12:00",
  "birth_place":  "東京都",
  "gender":       "female",
  "day_boundary": "23:00",
  "writing": {
    "tone": { "sharpness": 40, "warmth": 80, "mystical": 20 },
    "focus_areas": ["career", "money"]
  }
}

raw_data に含まれる主なフィールド

フィールド内容
shichu.normalized_data正規化済みの四柱データ
shichu.structure_report命式の構造レポート
shichu.summaryサマリーデータ

Transit API

POST /api/calc/transit トランジット

指定日または現在の星回りを返します。day モードで1日分、month モードで31日分のトランジットデータを返します。

リクエストパラメータ

パラメータ型必須説明
birth_datestringrequired生年月日 YYYY-MM-DD
birth_timestringrequired出生時刻 HH:MM
latfloatrequired出生地の緯度
lonfloatrequired出生地の経度
target_datestringrequired起点日 YYYY-MM-DD
periodstringrequired"day" または "month"
namestringoptional名前（表示用）
birth_placestringoptional出生地（表示用）
writingobjectoptional文章生成トーン指定
period の挙動：
"day" → target_date を起点に1日分を返します。
"month" → target_date を起点に31日分を返します。
各日には moon_timepoints（朝・昼・夜の解釈素材）が含まれます。

interpreted_tags

interpreted_tags はAIが鑑定文を書くための中間解釈層です。raw_data を直接AIに断定させるのではなく、このタグを主軸に利用してください。

設計意図： 初期実装では厳密な判定よりも「読みに使える形を固定する」ことを優先しています。strength が高く basis に根拠が記載されているタグを優先してください。

タグ構造

{
  "id":           "saturn_pressure",
  "label":        "責任・制限・継続課題",
  "strength":     2,          // 0〜3 の強度スコア
  "category":     "timing",
  "basis":        ["Saturn square orb=1.2"],
  "writing_hint": "焦らず整える必要性として扱う"
}

フィールド説明

フィールド説明
idタグの識別子
label日本語ラベル（鑑定文のテーマとして使用）
strength0〜3 の強度スコア。高いものを優先。根拠が薄いものは 0
categoryタグのカテゴリ（timing / character / relationship など）
basis判定根拠の配列。空配列 [] の場合は低優先で扱う
writing_hintAIへの文章化ヒント。断定ではなく「扱い方」として参照する

利用時の優先ルール

1. strength が高いタグを優先する
2. basis が空のタグは補足程度に留める
3. writing_hint を参考に、断定ではなく傾向・可能性として記述する

handoff_yaml

handoff_yaml はAPIレスポンス全体をAIや別システムに渡しやすいYAML文字列として返すフィールドです。

用途説明
鑑定文生成AIへのプロンプトに handoff_yaml をそのまま貼り付けて使用できます
別システム連携他サービスへのデータ受け渡しフォーマットとして利用
手動検証計算結果の目視確認・デバッグ用途

writing_hints / writing パラメータ

リクエスト時に writing オブジェクトを渡すと、レスポンスの writing_hints に反映されます。AIによる文章生成時のトーン調整に使います。

tone フィールド（各 0〜100）

フィールド説明
sharpness文章の歯切れよさ・直截さ。高いほど断言調
warmth温かみ・寄り添い度。高いほど柔らかい表現
mystical神秘的・詩的な表現の度合い

focus_areas（配列）

鑑定の焦点を絞るためのキーワード配列です。

値意味
"career"仕事・キャリア・社会的役割
"love"恋愛・パートナーシップ
"money"金運・資産・経済的側面

占術計算は流派・暦法・補正方法により結果が異なる場合があります。本APIは一貫した計算仕様を提供することを目的としており、他サービス・他流派との結果の一致を保証するものではありません。
