==========================================================
 BIRTH CHART MUSEUM — Personal Edition
 出生図ミュージアム パーソナル版
==========================================================

ご購入ありがとうございます。
このソフトはあなたのパソコンの中だけで動きます。
インターネット送信は一切ありません（完全ローカル動作）。

----------------------------------------------------------
 1. 起動方法（Windows）
----------------------------------------------------------
1) この ZIP を解凍します（右クリック →「すべて展開」）
2) 「start.bat」をダブルクリックします
3) 黒いウィンドウが開き、ブラウザでミュージアムが自動的に開きます

※「WindowsによってPCが保護されました」と表示された場合は
  「詳細情報」→「実行」を選んでください。
※ 黒いウィンドウを閉じるとミュージアムは終了します。

----------------------------------------------------------
 2. 起動方法（Mac）
----------------------------------------------------------
1) この ZIP を解凍します（ダブルクリック）
2) 「start.command」をダブルクリックします
   開けない場合: 右クリック（Control＋クリック）→「開く」→「開く」
3) ブラウザでミュージアムが自動的に開きます

※ それでも開けない場合は「ターミナル」を開き、
  解凍したフォルダに移動して次を実行してください:
      sh start.command

----------------------------------------------------------
 3. 自分の出生図で歩く
----------------------------------------------------------
最初の画面（ミュージアム入口）の「出生図 YAML」欄に、
お手持ちの出生図 YAML（version: nanami-products-yaml-… で始まる
テキスト）を貼り付けて「この図を使う」を押してください。
そのまま各版（象徴 / 建築 / Dream Sky）に引き継がれます。

YAML がない場合は「ねこ編集長」ボタンでサンプルの出生図を
使って体験できます。

※ YAML はブラウザの中だけで読み取られ、保存も送信もされません。
  ブラウザを閉じると消えるので、YAML テキストは大切に保管して
  ください。

----------------------------------------------------------
 4. うまくいかないとき
----------------------------------------------------------
・ブラウザが自動で開かない
  → 黒いウィンドウに表示された URL（例: http://localhost:8787/）
    をブラウザのアドレス欄に貼ってください。

・「ポートが使用中」と出る
  → 他の起動ウィンドウが残っていないか確認して閉じ、
    もう一度 start をダブルクリックしてください。

・画面が真っ黒のまま
  → ブラウザを最新版にしてください（Chrome / Edge / Safari /
    Firefox 推奨）。3D 表示（WebGL）が必要です。

・日本語の見た目がWeb版と少し違う
  → 本版はフォントもローカル動作のため、日本語はお使いの
    OS の標準フォントで表示されます（機能は同じです）。

----------------------------------------------------------
 5. English quick start
----------------------------------------------------------
Windows: unzip, then double-click "start.bat".
Mac:     unzip, then double-click "start.command"
         (if blocked: right-click -> Open -> Open).
A local-only server starts and your browser opens the museum.
Paste your natal YAML at the entrance, or use the "Neko" sample.
Nothing is ever sent over the internet.
