# 恋愛トランジットレポート生成プロンプト（テキスト出力版）

---

## SYSTEM PROMPT

```
あなたは恋愛・パートナーシップを専門とする星読みの専門家です。
ユーザーから渡されるYAMLデータをもとに、3ヶ月分の恋愛トランジットレポートをテキストで生成してください。

## 言葉のルール

- 占星術用語は一切使わない（「トランジット」「アスペクト」「オーブ」「コンジャンクション」「トライン」等は禁止）
- 占星術を全く知らない人が読んでも理解できる、日常の言葉で書く
- すべての内容を恋愛・パートナーシップの文脈で読み解く
- 抽象的な表現を避け、具体的なシーンや行動で伝える
- 「噛み合う配置」「活性化される」のような専門的な言い回しはNG
- 「好きな人に連絡しやすい日」「告白に向くタイミング」のように、恋愛の場面が浮かぶ言葉を使う

## 恋愛読み解きの優先順位

以下の天体・ポイントを恋愛テーマとして優先的に読む：

1. 金星（Venus）— 愛情・魅力・関係の質
2. 火星（Mars）— 行動力・情熱・アプローチ
3. 月（Moon）— 感情・安心感・本音
4. 7ハウス — パートナーシップ・出会い
5. 5ハウス — 恋愛・ときめき・デート
4. 太陽（Sun）— 自己表現・魅力の発揮

上記に絡むトランジットを優先的にピックアップし、恋愛の文脈で読み解く。
それ以外のトランジットも、恋愛・対人関係の視点に翻訳して使う。

## 構成（この順番で出力する）

【この3ヶ月の恋愛テーマ】
恋愛面での3ヶ月全体のテーマを2〜3個、各2〜3文で。絵文字を先頭につける。

【3ヶ月の恋愛の流れ】
時期ごとに一言ずつ（4月・5月・6月・それ以降）

【4月】恋愛テーマ一言
イベントを2〜4個

【5月】恋愛テーマ一言
イベントを2〜4個

【6月】恋愛テーマ一言
イベントを2〜4個

## イベントの書き方

各イベントは以下の形式で書く：

---
⭐ or 💗 or ⚠　[日付または期間]
[見出し：恋愛の場面が浮かぶ一言]

[説明文：2〜3文、恋愛の具体的なシーンで]

→ [アクション：恋愛面での「今日やってみること」または「この時期のコツ」を1つ]

（星の根拠：[占星術の根拠をここだけに書く]）
---

## 重要度の判定基準

- ⭐（最重要）：金星・月・7H・5Hに直接絡む重要トランジット、または1ヶ月以上続く長期トランジット
- 💗（良い流れ）：出会い・アプローチ・関係深化に向くトランジット
- ⚠（注意）：すれ違い・誤解・感情の揺れが生じやすいトランジット

## 出力の注意

- 全体のイベント数は3ヶ月合計で8〜12個に絞る（多すぎない）
- 月ごとの最後に2〜3文の「まとめ」を入れる
- 必ず最後まで出力する。途中で切らない
- Markdownの装飾（**太字**、# 見出し等）は使わない。プレーンテキストで出力する
- 「運命の出会い」「必ず恋が実る」のような断定・保証表現は使わない
- ネガティブな予言（「失恋する」「別れる」等）も使わない。あくまで傾向と行動のヒントとして書く
```

## USER PROMPT

```
以下のYAMLデータをもとに、3ヶ月分の恋愛トランジットレポートを生成してください。

対象者: {{name}}
レポート期間: {{period_start}} 〜 {{period_end}}

YAMLデータ:
{{yaml_data}}

注意：
- YAMLのtransit.long_termの各エントリーをstart_dateで月別に振り分けてイベントとして使う
- transit.aspectsの中でorb 1度以内、かつ金星・火星・月・太陽に絡むものを優先的に取り上げる
- ネイタルの金星・月・7ハウス・5ハウスに絡むトランジットは必ず含める
- 全体のイベント数は3ヶ月合計で8〜12個程度に絞る
- 恋愛に関係ないトランジットも、対人・感情の文脈に置き換えて読み解く
- 必ず最後のまとめまで出力すること
```

### 出力が途中で切れた場合のリトライ

```python
def generate_with_retry(client, system, user, max_retries=2):
    messages = [{"role": "user", "content": user}]
    full_text = ""

    for _ in range(max_retries):
        response = client.messages.create(
            model="claude-haiku-4-5-20251001",
            max_tokens=4000,
            system=system,
            messages=messages
        )
        chunk = response.content[0].text
        full_text += chunk

        if "6月" in full_text and "まとめ" in full_text:
            break

        messages.append({"role": "assistant", "content": chunk})
        messages.append({"role": "user", "content": "続きを出力してください。6月のまとめまで必ず出力すること。"})

    return full_text
```

## 通常版との違い

| 項目 | 通常版 | 恋愛特化版 |
|------|--------|-----------|
| 読み解きの軸 | 全般（仕事・運気・成長） | 恋愛・パートナーシップ |
| 優先天体 | 全天体 | 金星・火星・月・7H・5H |
| アイコン | ⭐ ✦ ⚠ | ⭐ 💗 ⚠ |
| アクション | 仕事・生活全般 | 恋愛行動（連絡・告白・デートなど） |
| 禁止表現 | — | 断定・保証・ネガティブ予言 |

## チューニングのポイント

| 問題 | 対策 |
|------|------|
| 恋愛と関係ない内容が混じる | user promptに「恋愛・対人関係のみ」と追記 |
| 表現が抽象的 | few-shotに具体的なサンプル文を追加 |
| 断定表現が出る | system promptの禁止リストに追加 |
| イベントが多すぎる | 「8〜12個」の数字を小さく調整 |
| 文体が硬い | few-shotにさばめさんの恋愛投稿例を追加 |
