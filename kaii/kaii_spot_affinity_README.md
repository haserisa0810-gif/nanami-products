# Kaii Spot Affinity

怪異スポット相性盤です。既存の「怪異探知機」と名前が重ならないよう、場所・怪異スポット相性に特化した別ファイルとして置いています。

## 使い方

```powershell
cd "C:\Users\haser\dev\nanami-products\kaii"
python -m http.server 5174 --bind 127.0.0.1
```

ブラウザで `http://127.0.0.1:5174/kaii_spot_affinity.html` を開いてください。

## メモ

- OpenAI / Claude / Gemini API は使っていません。
- 現在地取得はブラウザの Geolocation API を使います。
- 現在地を許可しない場合は、緯度・経度を手入力できます。
- 通常はOpenStreetMap/Overpass APIの公開データから、半径3km前後の公園・橋・トンネル・観光地・史跡などを候補にします。
- 周辺候補を取得できない場合は、場所タイプ診断にフォールバックします。
- `kaii_spots.json` は固定スポットではなく、フォールバック用の場所タイプ例です。
- 候補は公開空間・観光・史跡系の場所タイプのみを対象にします。
- 個人宅、私有地、立入禁止区域、現役の学校・病院・福祉施設、事件事故を連想させる実名地点は表示対象にしません。
- 判定は霊の存在や危険の判定ではなく、雰囲気相性を読むエンタメ用です。
