# AI占い for AI｜15秒縦動画 制作指示書（シナリオ・絵コンテ）

アニメーション実装者（Codex）向けのハンドオフ資料。素材はすべて本フォルダ
`tmp_youtube/` に揃っている。**セリフ音声・BGM・一枚絵は既存のものを使うこと**
（再生成不要）。

## 1. 完成品仕様

| 項目 | 値 |
|---|---|
| 長さ | 15.00 秒ちょうど |
| 解像度 | 1080×1920（縦 9:16） |
| フレームレート | 30fps |
| 映像コーデック | H.264（libx264, CRF 18, yuv420p, faststart） |
| 音声 | AAC 192kbps（キャラボイス2役＋BGM） |
| トーン | 少女漫画アニメ風。夜の部屋、紫×星空、キラキラ、ソフトグロー |
| 必須要件 | **セリフ音声と同期した口パク**（ナレーション不可、キャラの発話のみ） |

## 2. キャラクター

- **ミオ**（相談者）: 紫がかったボブヘアの女の子。パジャマ風の部屋着。
  スマホで「AI占い for AI」を使っている。声 = `voice_mio_*.wav`。
- **ルナ**（AI占い師）: 藍色ロングヘアに星飾り。アプリから現れる半透明の
  ホログラム。星をまとった衣装。落ち着いた大人の声 = `voice_luna_0.wav`。

## 3. 素材一覧（すべて同フォルダ、941×1672 px の一枚絵4枚）

| ファイル | 内容 | 使うシーン |

| `scene3_advice.png` | ルナが両手を差し伸べて助言 | S3 |

余るのでカメラワークのパン余白に使う）。

## 4. タイムライン絵コンテ

シーン切替はクロスフェード 0.15 秒程度。セリフ開始時刻は音声ファイルの
頭出し位置（ミリ秒単位でこの通りに adelay すること）。

### S1｜0.00–3.30s｜占い鑑定モード（素材: keyart.png）
- 画面上部にアプリUI風の鑑定結果カードをオーバーレイ:
  - タイトル「今日の鑑定結果」/「恋愛運 ★★★★☆→★5に変化(t≈1.2s)」
  - 1行ずつ表示: 「片思いは、進展の兆しあり。」(t≈0.7s)
    「鍵は『自分から話しかける勇気』。」(t≈1.6s)
- **セリフ**: ミオ `voice_mio_0.wav` **開始 0.40s**
  「鑑定モード、私の恋愛傾向まで分かるんだ。」
- 口パク: ミオの口（keyart 内座標 目安 x≈320, y≈790 ±10px）
- カメラ: ミオの顔へゆっくりプッシュイン（ズーム 1.00→1.06）
- 演出: 画面全体に星の粒がゆっくり舞う。ヘッダー「AI占い for AI」＋
  モードチップ「占い鑑定モード」（紫）

### S2｜3.30–6.90s｜相談モード・質問（素材: scene2_question.png）
- モードチップが「相談モード」（青緑）に切替
- チャットUI風の吹き出し（右寄せ・紫）にセリフがタイピング表示
- **セリフ**: ミオ `voice_mio_1.wav` **開始 3.55s**
  「ルナ、片思いの彼に、どうアプローチすればいい？」
- 口パク: ミオの口（scene2 内座標 目安 x≈330, y≈795）
- カメラ: ミオ寄り → 終盤にルナ側へ視線誘導のゆるいパン
- 演出: セリフ終わり（t≈6.0s〜）にルナ側で「…」タイピングインジケータ

### S3｜6.90–12.00s｜相談モード・助言（素材: scene3_advice.png）
- **セリフ**: ルナ `voice_luna_0.wav` **開始 7.00s**
  「まず短い会話を増やして。彼の好きな話題から、自然に誘ってみて。」
- 口パク: ルナの口（scene3 内座標 目安 x≈660, y≈470）
- カメラ: ルナの顔へプッシュイン。彼女の周囲に光の輪・星がきらめく
- 演出: 助言テキストの吹き出し（白・青緑縁）がタイピング表示。
  ルナのホログラム感を出すため、輪郭に淡い青グロー（加算合成）を薄く重ねる

### S4｜12.00–15.00s｜決意＋エンドカード（素材: scene4_resolve.png）
- **セリフ**: ミオ `voice_mio_2.wav` **開始 12.15s**
  「わかった。今日、話しかけてみる！」
- 口パク: ミオの口（scene4 内座標 目安 x≈310, y≈828）
- カメラ: ミオの笑顔へ軽くズーム、画面全体がわずかに明るく
- 演出: キラキラ増量（少女漫画の決意カット）。**t=13.9s〜** エンドカード
  フェードイン: 「占いを、次の一歩に。」＋小さく「AI占い for AI」

### 字幕(共通)
- 全セリフに画面下部の字幕バー（半透明黒・白文字・縁取り）＋話者チップ
  （ミオ=紫 / AI占い師 ルナ=青緑）。ミュート視聴でも内容が分かるように。

## 5. 口パク実装の指定

1. 各セリフ wav の RMS エンベロープを 30fps でサンプリング
   （窓 ≈ ±26ms、`clip((rms-0.015)*10.5, 0, 1)`、アタック速め・
   ディケイ 0.68 くらいの平滑化が自然だった）。
2. エンベロープ値 0〜1 を口の開き量にマッピング。
   - 0.07 未満: 元絵の口のまま（閉口）
   - それ以上: 塗りに馴染む開口合成。口内は暗い赤茶、輪郭はガウスぼかしで
     フェザリング。唇色・肌色は元絵周辺からサンプリングして違和感を消す。
   - 顎領域（口の下 ~40px）を開き量に応じ 4〜8px 下方に変形（フェザー付き
     パッチ移動）すると「顎が動く」感が出る。
3. 話者以外の口は動かさない。
4. 口座標は上記目安値。**実装時に必ず拡大表示で微調整すること。**

## 6. 音声ミックス

- 各 wav を開始時刻どおり adelay、音量 1.3
- BGM `music.wav` 音量 0.26
- amix 後に `alimiter=limit=0.95`
